# Security policy

RepoPilot is an AI agent that may execute commands and modify source code. Run it in an isolated environment, review proposed diffs, and never provide credentials with more permissions than the task requires.

## Reporting a vulnerability

Do **not** report security issues in a public issue. Use GitHub's private vulnerability reporting for this repository if enabled:

https://github.com/envy-ux/RepoPilot/security/advisories/new

If private vulnerability reporting is not enabled, contact the repository maintainer through a private channel listed on the repository profile. Do not include API keys, access tokens, or private repository contents in public reports.
